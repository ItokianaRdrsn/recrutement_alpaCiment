# Frontend React - Recrutement AlpA Ciment

Ce dossier contient le frontend React séparé du backend Laravel.

## Lancer le frontend

```bash
npm install
npm run dev
```

URL par défaut :

```text
http://127.0.0.1:5173/dashboard
```

## Backend attendu

Laravel doit tourner sur :

```text
http://127.0.0.1:8000
```

Le proxy Vite redirige `/api` et `/logout` vers Laravel.
