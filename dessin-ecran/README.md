# RecruitFlow Prototype

Prototype statique en HTML, CSS et JavaScript pour valider l'UX du projet de recrutement en mode multi-pages.

## Pages

- `index.html` pour le dashboard
- `offers.html` pour la gestion d'offre d'emploi
- `offre-detail.html` pour le détail d'une offre, ses compétences et ses candidatures
- `applications.html` pour le dépôt candidature
- `gestion-candidature.html` pour le suivi candidat
- `vivier.html` pour le vivier général et la recherche par direction/compétence
- `domaines.html` pour la validation des domaines spontanés
- `competences.html` pour le référentiel et le matching
- `validation.html` pour la validation des extractions CV
- `planning.html` pour la planification des tests et entretiens
- `communication.html` pour les modèles et l'historique
- `settings.html` pour les paramètres de message
- `postuler.html` pour le formulaire public candidat

## Ce qui est inclus

- Navigation latérale entre les modules internes
- Formulaire public de candidature sur offre ou spontanée
- Simulations légères en JavaScript pour les offres, les templates et quelques actions UX
